# Данные и расчёты

## Каталог и составы

Версия каталога — РРЦ с НДС 4Q 2026. Публичные данные содержат 56 артикулов, названия, описания, РРЦ и разрешённые товарные изображения. В интерфейсе и выгрузке расчёт ведётся в рублях. Сумма строки равна количеству, умноженному на РРЦ. Сводка равна сумме строк.

- У каждого из шести помещений B2C три самостоятельных состава. Сумма и список артикулов рассчитываются из 82 утверждённых строк.
- БСК содержит 103 строки белой базы для четырёх планировок. Максимум берёт все позиции белого блока. Включение в каждую из четырёх функциональных альтернатив определяется положительным значением соответствующей исходной колонки L–O.
- Студия содержит две розетки ATN000145Z в белом блоке. Каталог переводит их в парный ATN001045Z для карбона.
- Белый и карбон используют один состав. Меняются только подтверждённые пары ЭУИ, их цены и изображения. Комбинации двух цветов сверяются отдельно.
- У решений библиотеки свой состав. Для презентационных позиций без числа по умолчанию берётся один экземпляр. У «Умного света» цену формируют выбранные количества. Реле из прайса имеют указанную дату начала продаж 9 декабря 2026. Наличие проверяется при заказе.
- При ручном добавлении модуля к S/M/L совпадающий SKU считается общим и учитывается по наибольшему из двух количеств. Это явно показано при выборе модуля.
- Фотографии лампы A70 Matter SBDV-00306 и фисташковой SberBoom Home SBDV-00171V в приложенных разрешённых ассетах отсутствовали. Для этих позиций предусмотрен символ типа устройства.

## Комплект, сценарии и спецификация

Выбранные уровни комнат и явно добавленные сценарии сохраняются как разные источники. При нескольких источниках используется максимальное количество одного артикула в той же комнате. Строки разных комнат считаются отдельно. Изменение уровня заменяет его источник целиком. Зависимости сценария проверяются по SKU, физическому количеству и по условиям демонстрации. Партнёрские устройства не имеют ценовых позиций.

БСК и проекты ремонта выгружают один объект. XLSX содержит помещение, название, SKU, цвет, количество, РРЦ, итоговые формулы и размещение при ручной корректировке. Для функциональной планировки и проекта указаны выбранная категория или задачи. План, монтажные точки и размеры служат иллюстрацией. Диаметр ввода, нейтраль, крепление, цоколь и нагрузку проверяют на объекте.

## Проверка совместимости

- SberBoom Home работает с Zigbee. Для Zigbee-связок без хаба в составе указывается требование совместимого устройства.
- Matter-лампа имеет собственное питание. У обычных светильников через выключатель доступны состояния «включено» и «выключено».
- Отдельный датчик воды отправляет сигнал. Приводами управляет СЗОП. Внешний датчик для сценария между помещениями требует связки, хаба и интернета.
- Климатическая реакция ускорена. Термостат пола и терморегулятор радиатора показывают разные состояния.
- Чайник, робот, увлажнитель и шторы демонстрируют возможности совместимых моделей с подходящей настройкой. У розетки в сценариях отключается только назначенный допустимый прибор.
