# Умный дом в действии · релиз 2

[Открыть опубликованный прототип](https://artemefik888-dev.github.io/sber-smart-home-experience/)

Витрина и интерактивная квартира помогают попробовать домашние сценарии, собрать комплект для себя или подготовить состав на одну квартиру для сметы.

- **Для дома** — шесть комнат, интерактивные устройства, виджет «Салют», 3D-тур, каталог ситуаций, 18 готовых наборов, комплект и демо-заказ.
- **Для ремонта** — четыре типовые планировки, пять вариантов на квартиру, шесть готовых решений, подбор под проект и демо-разметка 2К с ручной проверкой. Состав выгружается в Excel.
- **Для девелопера** — типовые квартиры и готовые решения, комплекты S/M/L и четыре дополнительных модуля. Спецификация выгружается на одну квартиру.
- **Сценарии V2** — 35 комнатных сценариев B2C, девять вариантов для оснащения B2B и три истории всей квартиры. Совместимые партнёрские устройства участвуют в демонстрации и исключены из расчёта.

## Проверка и локальный запуск

Нужны Node.js 22+ и Python 3. У приложения нет устанавливаемых зависимостей.

```bash
npm test
npm start
```

[Локальный прототип](http://localhost:4173/)

Push в `main` запускает тесты и публикацию каталога `site` по прежнему адресу GitHub Pages. Сценарии, «Салют» и разметка 2К работают в демонстрационном режиме. Цены относятся к согласованному РРЦ 4Q 2026. Заказы, платежи и заявки не отправляются.
