# Безопасный откат

Перед каждым крупным выпуском создаётся аннотированный стабильный тег. Для отката публичной версии не переписывайте историю `main` и не используйте force push.

```bash
git switch main
git pull --ff-only
git revert --no-edit <commit-to-revert>
git push origin main
```

GitHub Pages автоматически опубликует новый revert-коммит. Стабильный тег позволяет проверить SHA и локально сравнить версии до отката.
