# Умный дом в действии

Публичный кликабельный прототип SberDevices для демонстрации бытовых сценариев умного дома, подбора комплектов по комнатам и обсуждения B2B-канала.

## Что работает

- Главная с интерактивной визуализацией всей квартиры и восемью комнатами.
- Покомнатные сценарии Свет / Климат / Безопасность с управляемой демонстрацией.
- Выбор Белый / Карбон для выключателей AtlasDesign с изменением SKU, изображения и цены.
- Подбор по категориям, комнатам и бюджету, включая предупреждение о недостаточном бюджете.
- Готовые уровни Базовый / Комфорт / Максимум для каждой комнаты.
- Единый комплект, общий хаб, удаление сценариев, демо-корзина и демо-оформление.
- Демонстрационный B2B-выход с масштабированием состава на несколько объектов.
- Сохранение пользовательского выбора в `localStorage`.

Цены устройств берутся из разрешённых колонок A–E листа `Sber` приложенного прайса и отображаются как `РРЦ 4Q 2026`. В публичный репозиторий не включены коммерческие колонки, исходные Word/PDF/Excel и рабочая переписка.

## Локальный запуск

```bash
npm test
python3 -m http.server 4173 --directory site
```

После запуска откройте `http://localhost:4173/`.

## Публикация

Push в `main` запускает `.github/workflows/pages.yml`. Workflow проверяет каталог и публикует каталог `site` через GitHub Pages.

## Ограничения прототипа

- Рекомендации используют прозрачные демонстрационные правила, а не будущую сценарную машину.
- Оплата, наличие товаров, отправка B2C-заказа и B2B-заявки не выполняются.
- Устройства пользователя — обычный светильник, радиатор и подключённый прибор — показаны как окружение и не добавляются в стоимость.

Подробнее об источниках и допущениях: [docs/data-sources.md](docs/data-sources.md). Безопасный откат: [docs/rollback.md](docs/rollback.md).
